## Encoding, whitespace, and Unicode handling
Each raw dataset row is used verbatim from `raw/wikitext-2/<split>.raw`. The only transformation before noise/tokenization is `str.strip()` on the line (removes the leading space and trailing ` \n` that WikiText rows carry). No characters inside the line are altered. WikiText's literal `<unk>` strings and its spaced punctuation (`don 't`, ` , `) are left as-is. Encoding is UTF-8 end to end; non-ASCII code points (counted in the audit below) are preserved.
