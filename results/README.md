# results/

Machine-readable results, generated by the phase notebooks. Nothing here is hand-edited.

## `phase2/` (written by `phase2.ipynb`)

| Path | Contents |
|---|---|
| `grid_index.csv` | the 37 conditions with record counts, realized edits and file SHA-256 |
| `severity.csv`, `severity_records.csv` | requested p vs realized normalized MED (per seed; per record, paired by record ID) |
| `tokenizer_pipelines.json` | documentation cards for the two tokenizer pipelines |
| `<train_set>/per_record.parquet` | one row per record × condition × tokenizer × model: IDs, NLL sums (bits, nats), T, MED, diagnostics |
| `<train_set>/scores.csv` | the 222 required scores (q1, q2, P_mix) + 74 supplementary trigram q3 scores (`H_bits`, `H_nats`, `PP`, `T`) |
| `<train_set>/summary.csv` | 6 clean + 72 noisy required rows + 2 + 24 q3 rows, mean / min / max over seeds 11, 23, 47 |
| `<train_set>/within_pipeline.csv` | noisy − clean loss per seed (either sign), with target-count change |
| `<train_set>/context_benefit.csv` | H(q1) − H(q2), H(q1) − H(q3) and H(q1) − H(P_mix) per condition |
| `<train_set>/coverage.csv` | pooled unknown-token rate, pieces per span, continuation rate, token change |
| `<train_set>/token_type_breakdown.csv` | P_mix loss split by target type (word, `##`, unknown, `</s>`): share × bits = contribution to H |
| `<train_set>/vocab.csv`, `lambda_selection.csv` | frozen V and count statistics; all 15 λ candidates with clean-validation loss |
| `train_a1_slice/examples.md` | the three traceable error-analysis examples |
| `corpus_size_comparison.csv` | A1 slice vs full train, within tokenizer |
| `figures/*.png` | loss vs rate, loss decomposition by target type, context benefit, coverage, severity, corpus size |
| `run_info.json` | protocol / config / data hashes, frozen λ, environment, runtime |

`<train_set>` is `train_a1_slice` (primary baseline) or `train_full` (corpus-size extension).
